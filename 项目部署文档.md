# TBServer 项目部署文档

## 1 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| JDK | 17+ | 编译和运行 |
| MySQL | 8.0 | 数据库 |
| Maven | 3.8+ | 构建工具 |
| NATApp | — | 内网穿透（支付宝回调必需） |

## 2 数据库初始化

2.1 登录 MySQL，创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS taobao DEFAULT CHARACTER SET utf8;
```

2.2 项目使用 MyBatis Plus 的 `IdType.AUTO` 自动建表能力，首次启动时会自动生成所有表。也可以手动执行以下建表 SQL：

```sql
USE taobao;

CREATE TABLE admin (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(255) NOT NULL,
    password VARCHAR(255) NOT NULL
);

CREATE TABLE consumer (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(255) NOT NULL,
    password VARCHAR(255) NOT NULL,
    consumer_name VARCHAR(255),
    account_balance DECIMAL(10,2) DEFAULT 0,
    status INT DEFAULT 0,
    create_time DATETIME,
    update_time DATETIME
);

CREATE TABLE merchant (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(255) NOT NULL,
    password VARCHAR(255) NOT NULL,
    merchant_name VARCHAR(255),
    revenue DECIMAL(10,2) DEFAULT 0,
    status INT DEFAULT 0,
    create_time DATETIME,
    update_time DATETIME
);

CREATE TABLE product (
    id INT AUTO_INCREMENT PRIMARY KEY,
    merchant_id INT NOT NULL,
    product_name VARCHAR(255) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    stock INT NOT NULL DEFAULT 0,
    description VARCHAR(500),
    image VARCHAR(500),
    create_time DATETIME,
    update_time DATETIME
);

CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY,
    merchant_id INT NOT NULL,
    consumer_id INT NOT NULL,
    product_name VARCHAR(255) NOT NULL,
    total_amount DECIMAL(10,2) NOT NULL,
    status INT DEFAULT 1,
    temp_amount DECIMAL(10,2),
    receive_time DATETIME,
    create_time DATETIME,
    update_time DATETIME
);

CREATE TABLE cart (
    id INT AUTO_INCREMENT PRIMARY KEY,
    consumer_id INT NOT NULL,
    product_id INT NOT NULL,
    merchant_id INT NOT NULL,
    quantity INT DEFAULT 1,
    create_time DATETIME,
    UNIQUE KEY uk_consumer_product (consumer_id, product_id)
);

CREATE TABLE review (
    id INT AUTO_INCREMENT PRIMARY KEY,
    consumer_id INT NOT NULL,
    merchant_id INT NOT NULL,
    product_id INT NOT NULL,
    order_id INT NOT NULL UNIQUE,
    score INT NOT NULL,
    content TEXT,
    create_time DATETIME
);

CREATE TABLE refund (
    id INT AUTO_INCREMENT PRIMARY KEY,
    order_id INT NOT NULL UNIQUE,
    consumer_id INT NOT NULL,
    merchant_id INT NOT NULL,
    product_id INT NOT NULL,
    type INT NOT NULL,
    reason TEXT,
    status INT DEFAULT 1,
    create_time DATETIME,
    update_time DATETIME
);

CREATE TABLE chat_message (
    id INT AUTO_INCREMENT PRIMARY KEY,
    sender_id INT NOT NULL,
    sender_role VARCHAR(20) NOT NULL,
    receiver_id INT NOT NULL,
    receiver_role VARCHAR(20) NOT NULL,
    content TEXT NOT NULL,
    create_time DATETIME
);

-- 预置管理员账号（密码 MD5 对应 123456）
INSERT INTO admin (username, password) VALUES ('admin', 'e10adc3949ba59abbe56e057f20f883e');
```



## 3 配置文件

打开 `src/main/resources/application.yml`，修改以下配置：

### 3.1 数据库连接

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/taobao?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: 你的MySQL密码
```

### 3.2 支付宝沙箱（需要充值功能时才配置）

3.2.1 前往 [支付宝开放平台](https://open.alipay.com/) 注册，进入「开发者中心 → 沙箱环境」，获取：
  - APPID
  - 应用私钥（用支付宝密钥工具生成 RSA2 密钥对，上传应用公钥后获取）
  - 支付宝公钥（上传公钥后自动生成）

3.2.2 替换配置：

```yaml
alipay:
  app-id: 你的APPID
  merchant-private-key: "你的应用私钥"
  alipay-public-key: "你的支付宝公钥"
  gateway-url: https://openapi-sandbox.dl.alipaydev.com/gateway.do
  notify-url: http://你的natapp域名/taobao/alipay/notify
  return-url: http://localhost:8080/taobao/pay-result.html
```

### 3.3 NATApp 内网穿透（支付宝回调必需）

3.3.1 注册 [NATApp](https://natapp.cn/)，购买免费隧道，获取 authtoken。
3.3.2 下载客户端，本机启动：

```bash
natapp.exe -authtoken=你的authtoken
```

3.3.3 启动后命令行会显示公网域名（如 `http://abc.natappfree.cc`），将其填入 `application.yml` 的 `alipay.notify-url`。

> NATApp 免费隧道每次重启会换域名，需同步更新配置文件并重启服务。

## 4 构建与启动

### 4.1 开发环境（IDE）

在 IntelliJ IDEA 中直接运行 `TBServerApplication.java` 的 main 方法即可。IDEA 默认携带 `-parameters` 编译参数，无需额外配置。

### 4.2 Maven 命令行

```bash
# 清理 + 编译 + 打包
mvn clean package -DskipTests

# 启动
java -jar target/TBServer-0.0.1-SNAPSHOT.jar
```

### 4.3 启动参数

如果 Maven 编译时不带 `-parameters`（会导致 @RequestParam 绑定失败），在 pom.xml 的 maven-compiler-plugin 中添加：

```xml
<configuration>
    <parameters>true</parameters>
</configuration>
```

或者在启动命令中指定：

```bash
java -jar target/TBServer-0.0.1-SNAPSHOT.jar --server.port=8080
```

## 6 注意事项

- 上传的商品图片存储在应用根目录下的 `uploads/products/`，需确保该目录有写入权限
- 密码使用 MD5 加密，生产环境建议升级为 BCrypt
- 定时任务 `OrderCleanUpTask` 会在开发环境下每 10 分钟清理超 1 分钟的未支付订单，可根据需要调整
